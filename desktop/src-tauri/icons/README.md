# Icons

Intentionally empty in this patch. Generate locally before the first `npm run build`
(not needed for `npm run dev`):

```
cd desktop
npx tauri icon path/to/a/logo.png
```

No existing logo asset exists in this repo yet (unlike the original Antivirus repo,
which had `frontend/public/logo512.png`), so any reasonably square PNG works as a
placeholder until real branding exists.
